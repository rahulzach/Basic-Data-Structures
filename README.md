## How to Use

```bash
# Clone the repo
git clone https://github.com/rahulzach/Basic-Data-Structures.git
cd Basic-Data-Structures

# Compile any program
gcc stack_using_array.c -o stack_using_array

# Run it
./stack_using_array
```
